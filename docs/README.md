# Jernih Brantas Web

Static single-page demonstration of the Jernih Brantas monitoring interface.

## Local preview

Open `index.html` directly in a browser, or serve this folder with a local static server.

## Included features

- Responsive desktop and mobile layout
- Station map and selectable monitoring points
- Automatic four-second NTU simulation
- Monitor Mode, Field Mode, and analytics demonstration
- Data Trust labels for simulated and manual readings

The displayed values are a local demonstration and are not official environmental measurements.
