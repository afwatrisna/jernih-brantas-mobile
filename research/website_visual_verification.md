# Responsive Website Visual Verification

## Desktop viewport — 1280 × 800

The browser route renders the dedicated Jernih website rather than the native mobile view. The desktop layout shows the brand bar, workspace navigation, station sidebar, Monitor Mode hero, status card, Data Trust strip, and the next metric row without overlapping elements. The large status card retains clear hierarchy and the sidebar creates an effective monitor-focused desktop workspace.

## Mobile viewport — 390 × 844

The layout collapses to a single-column interface with a compact brand bar, horizontal workspace navigation, concise Monitor Mode introduction, horizontally scrollable station cards, status card, and stacked Data Trust information. Text, cards, and controls remain visible at the mobile width without horizontal page overflow.

## Result

The responsive structure presents distinct but coherent desktop and mobile web layouts. No visual correction was required from the captured views.
