# Map and Simulation Fix Validation

The standalone HTML was opened in a browser and observed across multiple simulation cycles. The first inspected state showed Malang Hulu at **9.7 NTU**, simulation cycle **1**, and **45** simulation records. A later inspected state showed Malang Hulu at **10.7 NTU**, simulation cycle **3**, and **55** simulation records. The station list values, active status card value, Data Trust timestamp, and record count all changed together.

The map now uses an SVG river path with the five monitoring markers positioned at the corresponding coordinates along the curved route. This removes the prior mismatch between the straight diagonal map line and the monitoring points on mobile.
