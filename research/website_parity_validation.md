At 1280 px wide, the browser version rendered the full dashboard workspace with desktop navigation, the four-section navigation set (Monitor, Field Mode, Analitik, Pengaturan), station sidebar, live simulation status, Data Trust information, dynamic metrics, and the corrected curved river map.
