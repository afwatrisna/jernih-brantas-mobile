# Demo mode for presentation

The dashboard now starts with both **Mode Simulasi** and **Data demo untuk presentasi** disabled. When available, Monitor and Analitik therefore show the latest Supabase reading by default; otherwise, the retained local baseline remains visible as paused simulation.

For tomorrow’s demonstration, open **Atur** and enable both toggles:

1. **Mode Simulasi** keeps the five station values changing for the demo.
2. **Data demo untuk presentasi** keeps Supabase test or live entries from replacing the demo display.

To return to the normal live-data view after the demo, turn off **Data demo untuk presentasi**. It changes only what is displayed; it neither deletes database rows nor changes Field Mode permissions. All simulated values remain illustrative and are not official environmental readings.
